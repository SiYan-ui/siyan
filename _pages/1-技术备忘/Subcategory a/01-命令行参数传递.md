# 1. `sys.argv`：命令行原始字符串列表

头文件：sys

一般`sys.argv[0]`为程序名

`sys.argv` 是一个列表，记录启动 Python 脚本时传入的所有参数。

```bash
python train.py --algo flashsac --task go2
```

`sys.argv`：

```python
sys.argv == ["train.py", "--algo", "flashsac", "--task", "go2"]
```

特点：

- 按照空格分割；
- 所有元素都是字符串；
- 带不带 `--`、`-`、`=` 都原样保留；
- 没有类型转换、没有默认值、没有帮助信息；
- 需要你自己遍历、判断、切片。


# 2. `argparse`：标准库命令行解析器

`argparse` 会读取 `sys.argv`，然后按定义的规则解析成结构化对象。

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--algo", default="ppo")
parser.add_argument("--task", default="go2")
args = parser.parse_args()

print(args.algo)   # flashsac
print(args.task)   # go2
```

特点：

- 支持 `--algo`、`-a`、位置参数、子命令；
- 自动做类型转换，比如 `type=int`；
- 自动生成 `-h/--help`；
- 参数缺失或类型错误会自动报错。


# 3. Hydra：YAML 配置组合框架

Hydra 不是普通 CLI 解析器，而是配置管理框架。

它做三件事：

1. 加载 YAML 配置文件；
2. 按 `defaults` 组合多个配置组；
3. 用命令行里的 `key=value` 覆盖配置。

```python
@hydra.main(version_base=None, config_path="conf", config_name="config")
def my_app(cfg: DictConfig) -> None:
    print(cfg.algo.algo)
```

运行时：

```bash
python train.py algo.seed=2 task=go2_joystick_flat/mujoco
```

特点：

- 参数写成 `algo.seed=2`，而不是 `--algo.seed 2`；
- 适合管理大量嵌套配置；
- 适合机器学习实验、多环境、多模型组合。

配置文件`config.yaml`开头的`defaults`会使用`task`参数引用其他参数文件并按照顺序覆盖当前参数，以此实现多任务选择

其中`_self_`代表当前文件

```yaml
defaults:
  - _self_
  - task: go2_joystick_flat/mujoco
```

# 三者关系

| 层级 | 工具 | 作用 | 典型形式 |
|---|---|---|---|
| 最底层 | `sys.argv` | 原始命令行字符串列表 | `["train.py", "--algo", "flashsac"]` |
| 中间层 | `argparse` | 解析 CLI 参数 | `--algo flashsac` |
| 高层 | `Hydra` | 组合 YAML 配置 | `algo.seed=2` |

UniLab 命令：

```bash
uv run train --algo flashsac --task go2_joystick_flat --sim mujoco
```
执行流程为：

1. `uv run` 在项目虚拟环境里启动 `train`；
2. `train` 入口先用 `argparse` 解析 `--algo`、`--task`、`--sim`；
3. 把这些参数转换成 Hydra 能识别的形式，比如 `task=go2_joystick_flat/mujoco`；
4. 底层脚本再通过 `@hydra.main` 组合 YAML 配置。
